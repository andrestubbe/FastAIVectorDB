TITLE:
FastAIVectorDB: JMH Benchmark - Sub-Millisecond Native SIMD Vector Search 🚀

DESCRIPTION:
Official OpenJDK JMH (Java Microbenchmark Harness) performance benchmark for FastAIVectorDB. Evaluating native C++ SSE2/AVX2 Cosine similarity search latency across 100, 1,000, and 10,000 vector scale indices.

BENCHMARK RESULTS (JMH):
- 100 Vectors Search: < 40 µs
- 1,000 Vectors Search: < 120 µs
- 10,000 Vectors SIMD Search: < 469 µs (Sub-Millisecond Retrieval)
- Heap Allocation: 0 Bytes during search loop (Zero-GC)

RUN BENCHMARK LOCALLY:
Execute `run-benchmark.bat` in the repository root.
